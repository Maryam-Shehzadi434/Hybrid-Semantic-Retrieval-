## Overview

This project implements a hybrid retrieval approach that combines:

- TF-IDF based keyword similarity
- Semantic similarity using word embeddings

The system retrieves the most relevant support tickets or text entries based on a user query.

A simple interactive web interface is provided using Streamlit.

---

## Features

- Custom text preprocessing pipeline
- TF-IDF based retrieval
- Semantic similarity search
- Hybrid ranking mechanism
- Interactive Streamlit interface
- Support for large `.pkl` model/data files using Git LFS
